# Phase 3 Train/Test Ratio Grid Plan

Date: 2026-08-17

Status update: this protocol was later approved and executed. See `docs/PHASE_3_TRAIN_TEST_RATIO_GRID_AUDIT.md` for audited results.

## Scope

This document defines a protocol-only full train/test class-ratio grid.

Train ratios:

- `1:1`
- `1:2`
- `1:3`
- `1:4`

Test ratios:

- `1:1`
- `1:2`
- `1:3`
- `1:4`

This creates a `4 x 4` grid for each model and seed.

## Config

- Protocol config: `configs/experiments/wdc_train_test_ratio_grid_protocol.json`
- Status: `protocol_locked_no_fit`
- Fit allowed: `false`

This protocol does not train models or write prediction files. A separate fit-enabled config and explicit user approval are required before execution.

## Dataset And Splits

- Dataset: WDC Products `80pair`
- Train source split: `train_small`
- Validation split: `valid_small`
- Test source split: `test_unseen_100un`

Validation remains fixed for threshold selection. Test ratios are generated by seeded negative sampling from `test_unseen_100un`.

## Interpretation

This grid separates two effects:

- Train-ratio effect: compare rows within the same test ratio while changing train ratio.
- Test-ratio effect: compare columns within the same train ratio while changing test ratio.

The diagonal cells, where train ratio equals test ratio, correspond to the earlier matched train/test protocol. The fixed-test protocol is different because it used the original `test_unseen_100un` ratio of `1:8`, which is outside this new `1:1` to `1:4` test-ratio grid.
